# Raspberry Pi Drive Sync Raspberry Pi Drive Sync is a personal application used to synchronize files between a private Raspberry Pi computer and the owner's Google Drive account. The application uses rclone and the Google Drive API to upload Garmin training reports, health-data exports, and related files to Google Drive. This application is intended solely for the owner's personal use. It does not provide a public service or allow other users to register. [Privacy Policy](privacy.html)
