Raspberry Pi Drive Sync
Personal-use application

Simple, private file synchronization.

Raspberry Pi Drive Sync is a personal application that synchronizes files between a Raspberry Pi computer and its owner's Google Drive account.

What does it do?

The application uses rclone and the Google Drive API to upload, download, and synchronize files belonging to the account owner.

Its primary purpose is to maintain personal backups and synchronize Garmin training reports and health-data exports.

Who can use it?

This application is intended exclusively for personal use by its owner. It is not offered as a public service and does not provide public user registration.

Privacy and security

Access to Google Drive requires authorization through Google's OAuth system. Authentication credentials are stored locally in the owner's rclone configuration.
